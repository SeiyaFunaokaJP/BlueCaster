# Лицензии

BlueCaster распространяется по двойной лицензии: на ваш выбор **Apache License 2.0** или **MIT License** (SPDX `Apache-2.0 OR MIT`). См. [LICENSE](https://github.com/SeiyaFunaokaJP/BlueCaster/blob/main/LICENSE), [LICENSE-APACHE](https://github.com/SeiyaFunaokaJP/BlueCaster/blob/main/LICENSE-APACHE) и [LICENSE-MIT](https://github.com/SeiyaFunaokaJP/BlueCaster/blob/main/LICENSE-MIT).

{: .warning }
Распространяемый `bluecaster-core.exe` содержит [BTstack](https://github.com/bluekitchen/btstack), лицензия которого разрешает использование и распространение только в **личных некоммерческих целях**. BlueCaster распространяется только целиком, как единый набор программ, поэтому это ограничение действует для всего выпуска. Коммерческие лицензии можно получить у BlueKitchen GmbH.

Сторонние компоненты (BTstack, libldac, libopenaptx, fdk-aac, кодировщик LHDC V5, libopus, кодировщик aptX Adaptive, крейты Rust, SolidJS и другие), их зафиксированные версии, лицензии, обязательства, а также сведения о патентах, товарных знаках и сертификации перечислены в файле **[THIRD_PARTY_LICENSES.md](https://github.com/SeiyaFunaokaJP/BlueCaster/blob/main/THIRD_PARTY_LICENSES.md)**. Этот файл и тексты лицензий входят в установщик и портативный ZIP-архив и лежат в папке `licenses/` рядом с программами. В разделе **О программе** есть ссылка на копию для вашей версии.
